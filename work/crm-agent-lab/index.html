CRM Agent Lab

A browser demo of a personal CRM agent workbench. The full product source is privately maintained.

What it is

CRM Agent Lab is a personal CRM project I independently developed and maintain, built on Pi Native CRM. The public repository is a browser demo, not the complete application.

In the demo you can open a sample opportunity, use the capability lab to organize customer information, inspect tool returns, or confirm a pending action. A “recorded real-model run” section replays two model sessions that used fictional data.

The demo uses fictional customers and opportunities. Replay data is desensitized, and interaction runs in the browser.
