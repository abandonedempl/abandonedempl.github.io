FarmGuard

Compliance and anomaly-investigation agent for livestock operations.

The system reached an internal pilot.

Problem

Livestock operations had to cross-check medication, vaccination, mortality, inventory, and environmental data by hand. Inconsistent investigation order made it easy to miss a critical check, and findings were hard to audit later.

Role

AI application development intern. I helped build a long-running compliance review agent, with responsibility for data modeling, tool access, investigation workflow, and quality evaluation, so operators could receive traceable risk reports.

Approach

  • I unified domain schemas for environment, veterinary drugs, inventory, mortality, and vaccination, then wrapped queries — environment curves, inventory-versus-medication checks, mortality statistics, and vaccination reviews — as MCP tools with a CLI for debugging. Every tool response carried shed, batch, time window, source, and timestamp, so the agent could gather evidence against an investigation plan.
  • Investigation steps were arranged as an executable SOP, with conditions for collecting more evidence, escalating, stopping, or asking for human confirmation. We compared this fixed flow with unconstrained investigation on abnormal cases, and found that the SOP reduced unhelpful tool calls while keeping report structure consistent.
  • For long investigations, platform rules, batch tasks, tool evidence, and historical summaries were split into context blocks with priority and character budgets. When the budget was exceeded, lower-priority history was summarized first and recoverable records were trimmed, while current rules, evidence citations, and unfinished steps were always retained.
  • Structured memory stored medication, vaccination, mortality, inventory, and disposition records as fact, decision, lesson, or open loop. Retrieval used FTS5 and BM25, filtered by farm, batch, time, and rule version. Memories below a relevance threshold were not injected, which reduced the chance that stale cases would mislead a later judgment.

Evaluation and outcome

A dataset of normal, abnormal, and ambiguous cases covered inventory mismatches, late vaccination records, unusual mortality, excess medication, and unreported environmental deterioration. Each run recorded the prompt, tool calls, evidence, and approval trace. Failures were attributed by evidence coverage, false positives, and unauthorized actions; after a schema, SOP, or prompt fix, cases were replayed to block regressions.
