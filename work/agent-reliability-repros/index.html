Agent reliability repros

Minimal, runnable reproductions of agent SDK reliability issues.

What it is

This repository holds small reproductions of agent SDK behavior. It currently includes a Mastra fetchWithRetry cancellation case: an already-aborted request still retried through backoff instead of settling promptly.

The reproduction uses the public API, counts fetch invocations, and starts a local HTTP server. No API keys or external model calls are required.

Upstream outcome

The project later fixed the cancellation path so aborted requests stop retrying. This repository is a reproduction, not the upstream fix.
